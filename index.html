SOOP UP순 실시간

게시글에 달린 댓글의 UP(추천) 수를 실시간으로 모아
순위표와 방송화면용 오버레이로 보여줍니다.

실시간 갱신
오버레이 링크 신청하기 스트리머 →
내 순위를 방송화면에 띄우는 링크를 받습니다. 아이디와 닉네임만 적어 SOOP 쪽지로 보내주시면, 확인 후 답장으로 링크를 보내드립니다.
지원자 UP 순위 보기 →
부문별 순위와 확정선, 접전 구간을 실시간으로 볼 수 있습니다. 추천수를 누르면 댓글 내용이, 프로필 사진을 누르면 방송국이 열립니다.
새 순위 페이지 만들기 →
다른 게시글로 순위 페이지를 만듭니다. 부문 나누기, 확정 인원, 마감 시계를 설정하고 공유 주소를 뽑을 수 있습니다.

오버레이 받는 순서

  1. 신청하기를 눌러 방송국 아이디와 닉네임을 적습니다.
  2. 신청서 만들기를 누르면 내용이 자동으로 복사됩니다.
  3. SOOP 쪽지 창 열기로 쪽지를 보냅니다. 보낸 사람 아이디가 함께 찍혀서 별도 인증이 필요 없습니다.
  4. 확인 후 답장으로 링크를 보내드립니다. 보통 하루 안에 처리됩니다.
  5. OBS나 프릭샷에서 브라우저 소스로 그 주소를 넣으면 끝입니다.
오버레이는 배경이 투명해서 방송화면 위에 그대로 얹힙니다.
내 줄이 금색으로 강조되고, 위아래 두 명씩과의 UP 차이가 함께 표시됩니다.
