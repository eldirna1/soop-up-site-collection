코드 발급 신청

대회 순위 페이지를 만들려면 발급 코드가 필요합니다.
아래 순서대로 진행하면 신청서가 만들어집니다. 확인 후 코드를 보내드립니다.

1방송국 정보 적기

SOOP 방송국 주소만 있으면 됩니다. 나머지는 연락을 위한 정보입니다.

2본인 방송국이 맞는지 확인

아이디를 적으면 그 아이디 전용 인증번호가 나옵니다. 방송국 주인만 할 수 있는 일을 시켜서 본인인지 확인하는 방식입니다.

내 인증번호
위에 아이디를 먼저 적어주세요
이 번호는 아이디마다 다르게 나오고, 다시 열어도 똑같이 나옵니다.
  1. SOOP 방송국 관리 화면에서 방송국 소개글을 엽니다.
  2. 소개글 아무 곳에나 인증 ------ 이라고 한 줄 넣고 저장합니다.
  3. 저장된 소개글이 보이도록 화면을 캡처합니다.
  4. 신청 결과를 받은 뒤에는 그 줄을 지워도 됩니다.

i발급 기준

아래를 모두 만족하면 보통 하루 안에 코드를 보내드립니다.

  • 실제로 열려 있는 SOOP 방송국일 것
  • 소개글에 인증번호가 들어간 캡처를 보낼 것
  • 최근 30일 안에 방송 기록이 있을 것
  • 방송국을 만든 지 30일이 지났을 것
  • 한 아이디당 코드는 하나 (대회가 여러 개여도 같은 코드로 씁니다)
  • 코드를 다른 사람에게 넘기면 회수됩니다
