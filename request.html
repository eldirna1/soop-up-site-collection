UP순 랭킹 링크 신청

게시글 UP 순위를 방송화면에 실시간으로 띄우는 링크를 만들어 드립니다.
아래를 채우면 신청서가 만들어집니다. 본인 방송국이 맞는지 확인한 뒤 링크를 보내드립니다.

1어디에 쓸 건지 적기

순위를 띄울 게시글 주소가 필요합니다. 아직 글을 안 올렸으면 먼저 올린 뒤에 신청해주세요.

페이지가 여러 개일 때 줄을 바꿔 주소를 여러 개 적어주세요.

2본인 방송국이 맞는지 확인

아이디를 적으면 그 아이디 전용 인증번호가 나옵니다. 방송국 주인만 할 수 있는 일을 시켜서 본인인지 확인하는 방식입니다.

내 인증번호
위에 아이디를 먼저 적어주세요
아이디마다 다르게 나오고, 다시 열어도 똑같이 나옵니다.
  1. SOOP 방송국 관리에서 방송국 소개글을 엽니다.
  2. 아무 곳에나 인증 ------ 이라고 한 줄 넣고 저장합니다.
  3. 저장된 소개글이 보이도록 화면을 캡처합니다.
  4. 링크를 받은 뒤에는 그 줄을 지워도 됩니다.

3신청서 보내기

신청서를 만든 뒤, SOOP 쪽지나 메일 중 편한 쪽으로 캡처 사진과 함께 보내주세요. 답장은 보내신 쪽으로 갑니다.

1번을 채우면 신청서가 여기에 만들어집니다.
SOOP 쪽지로 보내기 Gmail로 보내기 메일 앱으로 보내기
캡처 사진은 창이 열린 뒤에 직접 첨부해주세요. 버튼은 글만 채워줍니다.

4링크를 받은 뒤 (OBS에 넣기)

답장으로 받은 주소를 이렇게 넣으시면 방송화면에 뜹니다.

  1. OBS에서 소스 + → 브라우저 추가
  2. URL 칸에 받은 주소를 붙여넣기
  3. 너비 420, 높이 760 정도로 맞추기 (원하는 대로 조절 가능)
  4. 확인 누르고 크기·위치 조정

i발급 기준

아래를 모두 만족하면 보통 하루 안에 링크를 보내드립니다.

  • 실제로 열려 있는 SOOP 방송국일 것
  • 소개글에 인증번호가 들어간 캡처를 보낼 것
  • 게시글이 본인 방송국의 글일 것
  • 최근 30일 안에 방송 기록이 있을 것
  • 방송국을 만든 지 30일이 지났을 것
  • 받은 링크를 다른 사람에게 넘기지 말 것 (넘기면 막힙니다)
