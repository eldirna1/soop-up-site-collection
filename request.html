오버레이 링크 신청

내 순위를 방송화면에 실시간으로 띄우는 링크를 만들어 드립니다.
아래를 채우고 SOOP 쪽지로 보내주시면, 확인 후 링크를 답장으로 보내드립니다.

i발급 기준

아래를 만족하면 쪽지를 확인 후 빠른 시간 내로 링크를 보내드립니다.
(개발자가 외부에 있을 시 답변이 느릴 수 있습니다.)

  • 컨텐츠에 실제로 지원한 스트리머일 것 (댓글이 목록에 있어야 합니다)
  • 신청서에 적은 아이디와 쪽지를 보낸 아이디가 같을 것
  • 컨텐츠 조건에 부합한 스트리머일 것
  • 받은 링크를 다른 사람에게 넘기지 말 것

1내 방송국 적기

방송국 주소만 있으면 됩니다. 쪽지를 보내는 순간 누가 보냈는지 아이디가 함께 찍히기 때문에, 따로 인증 절차를 거치실 필요가 없습니다.

내 인증번호
위에 아이디를 먼저 적어주세요
신청서에 자동으로 들어갑니다. 따로 외우거나 옮겨 적지 않으셔도 됩니다.

2쪽지로 보내기

신청서는 자동으로 복사됩니다. 아래 버튼으로 방송국을 열고, 쪽지 버튼을 눌러 붙여넣어 보내주세요.

1번을 채우면 신청서가 여기에 만들어집니다.
받는 사람 방송국 열기 메일로 보내기

3받은 링크를 방송화면에 넣기

답장으로 받은 주소를 이렇게 넣으시면 방송화면에 뜹니다.

  1. OBS에서 소스 + → 브라우저 추가 (프릭샷은 웹 소스)
  2. URL 칸에 받은 주소를 붙여넣기
  3. 너비 400, 높이 390 정도로 맞추기
  4. 확인 누르고 크기·위치 조정

배경이 투명해서 방송화면 위에 그대로 얹힙니다. 내 줄이 금색으로 강조되고, 위아래 두 명씩과의 UP 차이가 아래에 나옵니다.

★관리자 · 링크 만들기

쪽지 보낸 아이디를 넣으면 인증번호가 맞는지 확인되고, 링크가 바로 만들어집니다.

신청서의 인증번호가 이것과 같아야 합니다
